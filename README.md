# מה אוכלים

אפליקציית אכילה אישית לליאב, לפי `meal-app-spec.html` (גרסה 1.0).

## הרצה
```
npm install
npm run dev        # פיתוח
npm test           # בדיקות מנוע (31)
npm run build      # PWA ל־dist/
```

## החלטות שנבחרו כברירת מחדל
- פלטפורמה: PWA (React + TypeScript + Vite), מותאם לאייפון ומותקן למסך הבית.
- אחסון: מקומי במכשיר (localStorage) לפיילוט. Supabase הוא השלב הבא לחשבון, גיבוי והתראות ברקע.
- מנוע קלוריות דטרמיניסטי; פענוח טקסט חופשי בלי AI.

## לא אומת עדיין
- התראות כשהאייפון נעול (דורש שרת Web Push ובדיקה על המכשיר, AC23).
- כשרות סניפים, נתוני מסעדות ישראליות, מחירים.
- שני משתמשים והרשאות שרת (אין שרת עדיין, AC33).
